\# Berlin Hotel ESG FastAPI Backend



FastAPI backend for the Berlin Hotel ESG Intelligence Platform.



\## Features



\- Hotel ESG API

\- ESG rankings

\- AI trust risk filtering

\- Zone-based hotel analysis

\- Recommendation engine

\- Cloud PostgreSQL integration



\## Stack



\- FastAPI

\- PostgreSQL (Neon)

\- SQLAlchemy

\- Render deployment



\## Deployment



Hosted on Render.
